# Project Camp API

A RESTful API for managing camp activities, reservations, and participant information.

## Features

- User authentication and authorization
- Camp management (create, read, update, delete)
- Activity scheduling and management
- Reservation system
- Participant tracking

## Installation

1. Clone the repository
2. Install dependencies
3. Configure environment variables
4. Run the application

## Usage

Start the server:
```bash
npm start
```

API endpoints are available at `http://localhost:3000`

## API Documentation

For detailed API documentation, see the [API docs](./docs/api.md)

## Technologies

- Node.js
- Express.js
- MongoDB
- JWT Authentication
